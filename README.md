# ProjectPulse AI

### Turn project conversations into actionable intelligence.

ProjectPulse AI is an AI-powered communication intelligence tool that converts unstructured project conversations into structured, actionable information.

Instead of manually reading long conversations, project members can analyze communication and quickly identify:

- Project summaries
- Decisions
- Action items
- Task owners
- Deadlines
- Priorities
- Unresolved issues
- Source messages behind extracted information

ProjectPulse AI also maintains a searchable project memory and allows users to ask questions about previous project conversations.

---

## Problem

Important project information is often buried inside communication channels such as:

- WhatsApp messages
- Emails
- Contractor conversations
- Client discussions
- Supplier updates
- Site conversations
- Drawing or revision discussions

For example:

> Client: Kitchen cabinets are approved with walnut finish.

> Project Manager: Vinay needs to send the final cabinet measurements by September 15.

> Contractor: Installation can start once measurements are received.

A person reading these conversations manually has to identify what was decided, who needs to do what, and when it needs to be completed.

ProjectPulse AI automates this process.
